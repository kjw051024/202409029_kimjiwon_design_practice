# 202409029 김지원 · 프로젝트 소개 카드

시각디자인 프로젝트 네 가지를 카드 형태로 소개하는 반응형 포트폴리오 웹페이지입니다.

## 주요 기능

- 프로젝트 분야별 필터
- 프로젝트 상세 보기 모달
- 데스크톱 2열 / 모바일 1열 반응형 구성
- 키보드 포커스와 모션 감소 설정 지원

## 실행 방법

별도의 설치 없이 `index.html` 파일을 브라우저에서 열면 실행됩니다.
